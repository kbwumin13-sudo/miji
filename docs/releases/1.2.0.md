# 觅迹 1.2.0

选中搜索结果即可在右侧查看文件与命中内容；预览栏可以收起，照片和视频可切换为缩略图网格浏览。

- 图片、PDF、Office 文档和代码预览，音视频点击后在面板内播放。
- PDF 自动显示匹配页，支持独立阅读窗口；新提取的文字层和 OCR 保存原始页码。
- 代码显示实际命中行；默认使用 VS Code、VS Code Insiders 或 Cursor 时可打开到行。
- 命中摘要与关键词高亮；`⌘C` 复制选中文件，`⌘⇧C` 复制路径，文本复制沿用系统行为。
- 预览按需加载，切换或收起时取消请求、停止播放；相同结果的后台刷新保持阅读与播放状态。
- 文件修改后、索引尚未更新时显示提示并停用过时页码或行号。

## 升级与兼容

保留现有索引、扫描范围和设置，无需重建。旧 PDF 有文字层时按需查页；旧扫描件的 OCR 正文继续可查，重新提取后才有页码定位。离线磁盘显示已保存内容，原文件预览需要磁盘在线。媒体格式取决于 macOS 支持。

Apple Silicon / macOS 14+。应用使用 ad-hoc 签名，尚未公证；首次启动方法见仓库 README。

## 验证

核心 187 项执行（186 通过、1 个可选大型基准跳过），应用 19 项通过；另复验实际扫描 PDF 的 OCR 页码映射。界面验收覆盖 PDF 第 2 页定位与高亮、代码第 4 行、缩略图网格、DOCX 系统预览和 H.264/AAC 视频播放。

下载 `Miji-1.2.0-macOS-arm64.zip`，使用同名 `.sha256` 校验安装包。
